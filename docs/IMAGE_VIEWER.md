# Native TV image viewer
Use Compose TV Material controls and native Image/Canvas, ImageDecoder on API 28+, BitmapFactory fallback, AnimatedImageDrawable where supported, AndroidX ExifInterface, ColorSpace and bounded LruCache. No second graphics engine or mandatory image-loading framework. Verify latest compatible stable dependencies before adoption.
Targets JPEG PNG BMP WebP GIF HEIF HEIC AVIF JPEG XL TIFF SVG RAW/DNG. Native decoding first; evaluate libavif, libjxl, libtiff, LibRaw and a safe SVG renderer only for verified gaps, after license/security/ABI/16 KiB review. Animated formats, HDR/Ultra HDR and wide gamut depend on actual API/display/decoder support. SVG is not universally supported by Android VectorDrawable; disable external resources and scripts in any SVG renderer.
Fullscreen AMOLED, D-pad navigation between images, zoom/pan/rotation, fit/fill, slideshow configurable interval, EXIF orientation, metadata, transparency, favorites and contextual rename/delete through shared storage operations with consent. Preserve focus and position when returning to explorer. No permanent modification of original image for display rotation.
Decode to viewport size; inspect dimensions before allocation, enforce pixel/byte limits and handle malformed images. Region decoding only for supported formats and seekable sources; bounded tile cache for zoom, no full-size decode by default. Cancellable background IO and decoding, bounded adjacent prefetch, no eager folder scan, stop animation/slideshow on lifecycle exit, release references and trim caches on memory pressure. Avoid unbounded network buffering; use shared provider streams and bounded temporary files only when required. No metadata leakage or cloud processing. Test large images, malformed inputs, EXIF orientations, animated lifecycle, unsupported formats, remote disconnect, revoked access, memory pressure, focus and accessibility. Measure decode latency, peak memory and frame timing before claiming gains.
