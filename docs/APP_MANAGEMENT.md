# Application and system storage management
Use PackageManager with scoped package visibility for TV/mobile launchable applications; do not claim complete inventory. Open official application details and system storage settings for cache/data clearing, uninstall, disable and permission management where supported. Evaluate QUERY_ALL_PACKAGES only if core functionality and distribution policy justify it; usage access for StorageStatsManager is optional and explicit. No root, accessibility automation, hidden APIs, forced process killing or private cache bypass. Own cache cleanup must exclude active files; accessible temporary files, incomplete downloads, APK installers, empty folders and potential residues are review candidates, never automatically junk. Show actual bytes, scope, risk, consent and failures. Protect system files and personal data; verify deletion and distinguish cache from app data. APK installation via system consent only. Test visibility, unavailable settings, revoked access and system apps.
