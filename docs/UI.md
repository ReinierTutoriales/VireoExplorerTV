# Native Android TV UI specification

## Platform and dependencies
Kotlin, Compose, AndroidX TV Material, Compose Foundation lazy layouts, Activity, Lifecycle/ViewModel, StateFlow and lifecycle-aware collection. Navigation only when screen complexity justifies it. Media3 for playback and media sessions. Use official current compatible stable releases verified before adoption; do not introduce a second mobile Material design system, WebView, cross-platform frameworks, custom rendering engines or animation dependencies. Use framework resources for localization and accessibility.

## Visual system
VireoTheme is the single source of colors and typography. Pure black #000000 window/content, #121212 surfaces, #80DCC0 accent, #F2F4F3 primary text. Native TV Material focus states, shapes, typography and motion; avoid decorative blur, gradients, shadows and continuous animation. Preserve readable ten-foot typography, safe margins, adaptive dimensions and contrast; no fixed 1080p assumptions. Use official Material Symbols Rounded vectors for required icons, imported as local VectorDrawable resources with provenance and applicable license notices; do not bundle an entire font or obsolete icon library. Native painterResource, semantic labels for actionable icons, no emoji substitutes in production. Verify upstream revision before importing; avoid unnecessary custom paths.

## Information architecture
Home: storage locations, accessible categories, favorites and recent files. Navigation destinations: files, network, cleaner, transfers, favorites and settings. Show only implemented destinations. Explorer: breadcrumb, list/grid, sort/filter/search, contextual actions and multi-selection; stable item identities, visible loading/empty/error states, contextual permission prompts. Media viewer uses native TV controls and Media3 sessions. Cleaner shows reasons, risk, review and confirmation. Network credentials use secure input and explicit trust decisions. Transfers expose progress, cancellation and failure recovery. No fabricated counts or placeholder features.

## Remote interaction
D-pad primary; native focus traversal, focus groups/restoration where justified, deterministic initial focus and back behavior. Preserve selected item and scroll position across navigation and refresh; handle removal of focused item with nearest valid fallback. Long press must not trigger dialog action on repeated DOWN or release; test repeated key events, back, fast navigation, dialogs and IME. All actions reachable without touch, accessible labels and meaningful selected/disabled states. Respect system accessibility and motion preferences. No global key interception unless proven necessary.

## Performance
LazyColumn/LazyVerticalGrid with stable keys and content types, bounded visible thumbnail requests, cancellable IO, no disk/network/metadata decoding on main thread. Use immutable UI snapshots and lifecycle-aware StateFlow collection; avoid broad recomposition and unstable lambdas where measured. Debounce search and coalesce progress updates; avoid per-frame allocations and unnecessary derived state. Decode thumbnails to target size, bounded memory cache, invalidate on changes, no eager full-resolution images. Do not scan storage or discover network during first frame; load on demand, cancel when no longer needed. Preserve state via ViewModel/SavedStateHandle where appropriate. No always-running UI timers or services. Use native image decoding first; add image loader only if measured requirements justify it. R8/resource shrink, baseline profiles and Macrobenchmark after runnable baseline. Track startup, frame timing/jank, memory, idle CPU, APK size and D-pad responsiveness on representative API/resource configurations. No performance claims without evidence.

## Acceptance
Build/lint/unit and relevant UI tests; verify initial focus, directional navigation, focus restoration, repeated key events, accessibility, font scaling, localization, long filenames, large folders, low memory, revoked permissions, USB removal, network disconnect and lifecycle recreation. Keep source and docs aligned; record exact dependency versions, upstream references and results. This is a target specification, not a claim of implemented screens or measured performance.

## Application management and intelligent cleanup
Follow docs/APP_MANAGEMENT.md as a binding contract. Include scoped installed-app inventory, system/user distinction, optional authorized storage and usage statistics, official app settings for cache/data/uninstall/disable, consent-based APK installation, accessible temporary/incomplete files, residual APKs, empty folders, own inactive cache and duplicate review. Never equate candidate names or age with junk. Protect system/private data, revalidate before deletion, preserve a duplicate, report actual reclaimed bytes and partial failures. No root, hidden APIs, forced process killing or fake RAM optimization. Verify permission eligibility and device capability; test revoked access, active files and unavailable settings. Keep UI native TV and operations bounded, cancellable and off the main thread. Implementation status belongs in IMPLEMENTATION.md.

## Explorer visual hierarchy (2026-11-25)
Default folder workspace is content-first: compact native icon navigation, adaptive 136dp minimum folder grid, details disclosed on demand, reduced decorative surfaces, clear folder symbols and single file-size metadata. Preserve list mode, D-pad selection, long press, file operations and media playback. Reference: https://developer.android.com/design/ui/tv/guides/styles/layouts ; https://developer.android.com/design/ui/tv/guides/components/cards ; https://developer.android.com/design/ui/tv/guides/styles/focus-system . Compose 1.13.0 and TV Material 1.1.0 verified against official stable metadata on 2026-11-25. Visual and runtime acceptance pending.

Use native NavigationDrawer/NavigationDrawerItem for folder navigation as well as home, rather than a manually implemented icon rail. Remote listings use native ListItem, uncluttered folder icons and one size field. Google official Compose performance skill: https://developer.android.com/agents/skills/jetpack-compose/jetpack-compose-performance/skill ; TV navigation drawer: https://developer.android.com/design/ui/tv/guides/components/navigation-drawer ; lazy TV layouts: https://developer.android.com/training/tv/playback/compose/lists . Do not substitute a mobile Material library for TV Material. Visual inspection and dependency graph audit remain acceptance gates.
