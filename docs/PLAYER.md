# Native TV player
Use latest verified compatible stable AndroidX Media3 ExoPlayer, MediaSession and native MediaCodec; prefer SurfaceView and official Compose media surface with TV Material controls. No external player dependency or duplicate playback engine. Hardware first, capability-based software fallback only for verified gaps. Preserve HDR and audio passthrough only where supported. Select tracks, language, embedded/external subtitles (SRT ASS SSA WebVTT TTML PGS VobSub subject to actual support), matching sidecar discovery, explicit file selection, caption preferences and offset where supported. Bitmap captions retain authored appearance; do not promise arbitrary styling. Resume position, speed, seek, aspect ratio, playlist, fullscreen, D-pad controls, accessible focus and deterministic back. Use MediaSession and audio focus, release player/surface on lifecycle exit, keep screen awake only during playback, handle noisy audio and interruptions. Local content URI and provider-backed seekable DataSource for network; bounded buffers, cancellation, reconnect, no whole-file downloads. Avoid TextureView unless required. Frame-rate matching through supported platform APIs, no forced refresh or HDR. Test track selection, malformed subtitles, missing codecs, seek, lifecycle, network loss, low memory, focus, HDR/audio capability matrix. Evaluate FFmpeg/libass and other extensions only after license, patent, ABI and performance review. No claims of universal codec support. Persist resume/settings locally; no telemetry. Validate dependencies against official release notes before pinning.
