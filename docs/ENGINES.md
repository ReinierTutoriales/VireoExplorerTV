# Engine specifications
All libraries below are candidates, not installed dependencies or verified latest versions. Before adoption verify official stable release, maintenance, transitive dependencies, security, Android compatibility, ABI/16 KiB pages, proprietary distribution and patent obligations. Record evidence. Avoid redundant decoders and protocol stacks.

## Storage and permissions
Unified provider capabilities: list/stat/read/write/create/rename/delete/seek, stable IDs, pagination, cancellation, streaming, free space, timestamps and optional atomic operations. SAF persisted grants, MediaStore, File API, StorageManager USB/SD; MANAGE_EXTERNAL_STORAGE only when eligible and explicitly granted, legacy permissions scoped by API, media permissions only if needed. No root or ADB prerequisite, no bypass of app-private directories or Android/data restrictions. Handle read-only, revoked grants, removed volumes, unavailable picker, low space, symlinks and provider errors. APK install through system PackageInstaller/user consent and eligible REQUEST_INSTALL_PACKAGES. Share via content URI grants; no broad exported components. Favorites, recents, search, sort, filters, hidden files, list/grid, multi-select, properties, thumbnails, create/rename/copy/move/delete. Verified cross-provider copy before deletion; explicit conflicts, partial cleanup, cancellation and bounded concurrency. Trash only where supported; no false undo guarantees.

## Multimedia
Media3 ExoPlayer, session, extractor, datasource and MediaCodec hardware first; AudioTrack/AudioSink, ImageDecoder/BitmapFactory native first. Targets AVC HEVC AV1 VP8 VP9 MPEG2 MPEG4 VC1; evaluate VVC. MKV MP4 MOV AVI WebM TS M2TS FLV OGG; AAC MP3 FLAC ALAC Opus Vorbis PCM WavPack AC3 EAC3 TrueHD DTS DTS-HD; JPEG PNG WebP AVIF HEIF HEIC JPEG XL GIF TIFF BMP SVG RAW/DNG; SRT ASS SSA WebVTT TTML PGS VobSub. HDR10 HDR10+ HLG Dolby Vision and passthrough only if supported by decoder/display/audio chain. Candidate selective FFmpeg LGPL-compatible build (no GPL/nonfree flags without owner review), dav1d, libjxl, libavif, LibRaw, libass. Patent and trademark obligations separate from copyright. No universal playback promise. Track selection, subtitles, resume, playlist, metadata, artwork, EXIF, zoom, slideshow, refresh-rate matching, network seek and bounded buffers. Test malformed media and resource limits.

## Network
SMBJ for SMB2/3; libnfs for NFS3/4; SSHJ for SFTP; Apache Commons Net for FTP/FTPS; OkHttp plus safe XML for WebDAV; lightweight SSDP/UPnP for DLNA; Android NsdManager for DNS-SD/mDNS; WS-Discovery for Windows. Verify candidates before adoption, especially Android compatibility and licensing. INTERNET and network-state permissions as needed; local-network runtime permission per target API, multicast lock only during discovery if needed. Manual host/port/share, discovery, favorites, auth, read/write capabilities, remote seek, cancellation, timeouts, reconnect and bounded discovery. SMB1 off, plaintext opt-in, verify TLS certificates and SSH host keys, SMB signing/encryption as supported. Android Keystore authenticated encryption for credentials, no secrets in logs/backups, no WAN exposure or persistent discovery service.

## Intelligence and cleaner
Local incremental index, Room only when justified, Coroutines/Flow, WorkManager deferred jobs, bounded scan depth/concurrency, cycle detection, cancellation, invalidation and cache limits. Classify by type/size/date, large/old files, duplicate content, redundant APK candidates, partial downloads, empty folders, potential accessible residues and own cache. Duplicate grouping by size then sampled hash then full SHA-256 and final byte comparison; revalidate identity before deletion and retain at least one copy. Age/name alone never proves junk. Explain reason/risk/space, preview and explicit consent, protect personal files and remote locations by default, revalidate before destructive actions, report partial failures. No private app data bypass, RAM boosters or automatic process killing. Use system-supported mechanisms for other apps. Test races, revoked access, symlink escape, duplicate preservation and cancellation.

## Archives and infrastructure
ZIP browse/create/extract using platform APIs where adequate; evaluate Apache Commons Compress for TAR/GZIP/BZIP2/XZ and other formats; 7z/RAR only after license and resource review. Reject traversal, symlink escape, archive bombs and excessive expansion; check free space. DataStore settings, Lifecycle/ViewModel, structured concurrency, bounded IO, R8, baseline profiles and Macrobenchmark when runnable. TV Material AMOLED and native D-pad focus. No always-on services without justified user-visible work; foreground service types and notifications only as required by platform. Dependency catalog, verification metadata, SBOM and notices; audit vulnerabilities and license compatibility. Tests cover API boundaries, low memory, storage removal, network failure, malformed input, startup, focus and accessibility. No claimed performance without measurements.
